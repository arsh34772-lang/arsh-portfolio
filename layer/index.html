03 — Capabilities

Built for the work that repeats.

Four things cover almost every request we get. Everything else is a branch of these four.

Automation

Triggers, steps, waits and retries. The plain middle of the product, and the part that saves the most hours.

Branching

Split on any value — amount, status, city, tag — and give each path its own rules, delays and retries.

Approvals

A step can wait for a human: approve, reject, or answer a question. One message, one tap, and the run continues.

Workflow history

Every run kept with its inputs, outputs and timing. Replay a failed run instead of rebuilding it by hand.
